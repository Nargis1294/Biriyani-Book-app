# Biriyani Book App

A Java Android App to learn OOP Concepts using Biriyani Recipes.

## Features
- View list of Biriyani Recipes
- See Ingredients and Cooking Steps
- Learn Encapsulation, Classes & Objects, ArrayList

## Files
- `Recipe.java` - Model class with private fields, constructor, getters
- `MainActivity.java` - Main logic to create and display recipes

## How to Run
1. Clone this repo
2. Open in Android Studio / VS Code
3. Run `MainActivity.java`
